# tryingsome

e621 전용 안드로이드 뷰어. 통신사 접속 차단(SNI 검사)을 앱 안에서 우회해요. VPN이 필요 없고 속도도 느려지지 않아요.

## 기능
- 태그 검색, 자동완성, 무한 스크롤
- 이미지, GIF, 동영상(webm/mp4) 보기, 두 번 탭하거나 손가락으로 확대
- **플래시(.swf) 재생**: 내장 [Ruffle](https://ruffle.rs) 에뮬레이터 사용
- 원본 저장 (사진/동영상/다운로드 폴더의 `tryingsome` 폴더)
- 블랙리스트 태그, e926(전체 이용가) 모드, e621 계정 로그인(선택)

## 차단 우회 원리
TLS 연결의 첫 데이터(ClientHello)에는 접속하려는 주소(SNI)가 평문으로 들어 있어요.
통신사는 이걸 보고 접속을 끊어요. 앱은 이 데이터를 둘로 쪼개 보내서(TLS 레코드 분할 / TCP 패킷 분할) 검사 장비가 주소를 알아보지 못하게 해요.
DNS 조작에 대비해 DNS-over-HTTPS도 써요. 다른 서버를 거치지 않아서 속도가 그대로예요.

설정 > 연결 테스트로 어떤 방식이 내 통신사에서 통하는지 확인할 수 있어요.

## 빌드
`main`에 푸시하면 GitHub Actions가 APK를 만들어서 [Releases](../../releases)에 올려요.
Ruffle 파일은 빌드할 때 npm에서 받아와요.

> 서명 키(`app/signing/`)는 업데이트 설치용 개인 키예요. 저장소가 공개라서 누구나 같은 키로 서명할 수 있어요. 이 APK는 이 저장소의 Releases에서만 받으세요.

만 18세 이상만 사용할 수 있어요.
